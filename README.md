# Weather App

A simple weather application built with HTML, CSS, and JavaScript. Enter any city name to get its current temperature and weather condition, powered by the OpenWeatherMap API.

## Features

- Search weather by city name
- Displays current temperature in Celsius
- Shows a short weather description (e.g. "broken clouds", "clear sky")
- Clean, simple UI

## Tech Stack

- HTML
- CSS
- JavaScript (Fetch API, Events, DOM)
- OpenWeatherMap API

## How to Run

1. Clone this repository
2. Open `index.html` in your browser
3. Enter a city name and click "Search" to see the current weather

## Notes

This project uses the OpenWeatherMap API, which requires a free API key. If you'd like to run this project with your own key, sign up at openweathermap.org and replace the `apiKey` value in `script.js`.
